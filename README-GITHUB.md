# Mahfel School — Juz 30

Static source ready for GitHub Pages. Upload **the contents** of this folder to a new public repository, and enable Settings > Pages > Deploy from branch `main` / `(root)`.

Open `index.html` or `game/index.html` explicitly (do not navigate just to the `game/` folder on `file://`).

Lantern assets are standalone lightweight SVG files in `game/assets/`. Original bitmap lanterns remain only as unused legacy files.

Audio demo may require internet; administrator media publishing still requires a backend for online sync.
