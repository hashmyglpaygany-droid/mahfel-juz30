# مدرسه محفل — جزء ۳۰ — نسخه کامل ۵

- صفحه اصلی: `index.html`
- بازی راز شش نور سوره ناس: `game/index.html`
- ۳۷ سوره جزء ۳۰ در کتابخانه و پنل مدیریت؛ فقط بازی سوره ناس فعلاً کامل است.
- فلش‌کارت/شنیدن/تکرار، تشخیص چندگزینه‌ای، ترتیب آیات، مرور از حفظ، ثانیه‌شمار و ۶ فانوس تصویری.
- استفاده از تصویر فانوس‌های تأییدشده برای حالت خاموش، آموزشی، تثبیت‌شده.
- اجرا روی ویندوز: `start-local.bat`، یا سرور `python -m http.server 8000` سپس `http://localhost:8000/`.
- فایل‌های رسانه اختصاصی هنوز باید وارد شوند. صوت آزمایشی آنلاین به اینترنت نیاز دارد. رابط پنل مدیریت فعلاً داده را در همین مرورگر نگه می‌دارد.
- مرورگر پیشنهادی Chrome؛ Internet Explorer پشتیبانی نمی‌شود.
