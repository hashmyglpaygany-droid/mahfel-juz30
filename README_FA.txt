مدرسه محفل - نسخه لوکال بازسازی شده

ویندوز: فایل start-local.bat را دوبار کلیک کن. اگر Python نصب باشد، localhost:8000 باز می‌شود. اگر نصب نباشد، index.html مستقیم باز می‌شود (ممکن است قابلیت ذخیره رسانه محدود باشد).
روش جایگزین: در همین پوشه Terminal باز کن و python -m http.server 8000 اجرا کن.
موبایل: در همان شبکه وای فای، آدرس IP داخلی لپ تاپ به همراه :8000 را باز کن. برای دسترسی ممکن است لازم باشد فایروال اجازه بدهد.

این نسخه پنل محلی نمونه است؛ تنظیمات و فایل ها بین کاربران همگام نمی شوند. فقط ناس، فلق و اخلاص متن نمونه دارند. صدای حاج احمد باید از قسمت مدیریت > صوت و ویدئو برای هر آیه بارگذاری شود.
